# MAGOPRENEUR · Tim Batagor (OKK 35 Unpad)

Website proyek aksi sosial Kampus Hejo dengan game **Feed The Maggot** dan chatbot **Kang Raka**.
Semua file sengaja diletakkan di satu tempat (tanpa folder) supaya mudah di-upload lewat GitHub.

| File | Isi |
|---|---|
| `index.html` | Halaman utama website |
| `game.html` | Game Feed The Maggot |
| `chatbot.js` | Data jawaban Kang Raka (dipakai website dan game) |
| `poster.jpg`, `logo-unpad.png`, `logo-tpb.jpg` | Gambar |
